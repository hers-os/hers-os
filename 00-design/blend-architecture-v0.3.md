## 1. Q3 覆寫細節：多人混上限 2 人

### 1.1 為什麼放寬

v0.2 Q3 採 C「先一個、跑滿 20 支再開」、保守理由是「先看單借會不會偏移」。
v0.3 緣緣判斷：1+1 雙借跟單借**性質不一樣**、單借跑 20 支再開、不會自動學會 1+1 的問題。要從第一版就有 1+1 的樣本、才知道哪邊會打架。

### 1.2 新規則

| 條目 | 規則 |
|---|---|
| **同時借人數上限** | 2 人（含 0 人 = 純緣緣、1 人 = 單借、2 人 = 雙借） |
| **強度加總上限** | 兩人加總不可超過 **50%**（強+弱 OK、強+強不行） |
| **借的層可重疊** | OK、但生成時兩條判斷邏輯**必須能融合、不能打架** |
| **打架定義** | 兩 reference 在同一層的「結論」直接矛盾（例：A 主張真誠、B 主張包裝）|
| **打架處理** | skill 不自動裁決、回問使用者選一個主導、另一個讓位 |
| **metadata 義務** | 雙借支必須 `borrow_total_strength_pct` ≤ 50、且註記是雙借 |
| **20 支審查順序** | 累計到 20 支時、雙借支**優先抽看**、單借支次之 |

### 1.3 不變的部分

- 「主大腦唯一 = 緣緣」原則不變
- 嘴 100% 緣緣不變
- ✅ 三借 / 🚫 三鎖層不變
- tier-A 用過即忘、tier-C 禁用不變

## 2. Q4 覆寫細節：對話式入口

### 2.1 為什麼改

v0.2 預定指令格式 `/blend topic="..." borrow="X:層[強度]"` 在實作時發現幾個問題：

1. **參數順序記不住**：使用者要記住 borrow 的字串格式、跟 layer 名稱、跟強度標記
2. **無校準包檢查**：使用者下指令時不會知道 reference 還沒被校準
3. **缺對話式紅線提醒**：例如使用者要借「服務對象」（鎖死層）時、指令會接受、但對話式會在當下擋下並解釋

### 2.2 新規則

入口從「指令」改成「對話」。skill `script-blender` 的觸發條件改成：

- 使用者表達想寫腳本（「我要寫一支聊 X」「來一支 Reels」「幫我寫個 60 秒短影音」「blend 一支關於 Y 的」⋯⋯）
- 不需要任何固定指令前綴
- skill 觸發後、按 SKILL.md 第 1 節的 4 輪對話收集完 7 個欄位、再生成

### 2.3 對話收集的 7 個欄位

| # | 欄位 | 必填 | 預設 |
|---|---|---|---|
| 1 | 主題 | ✅ | 無 |
| 2 | 借不借 | ✅ | 無 |
| 3 | 借誰（最多 2 人） | 借時必填 | 無 |
| 4 | 借哪一層（限 ✅ 三層） | 借時必填 | 無 |
| 5 | 強度 | 借時必填 | 中 |
| 6 | 平台 | ✅ | 無 |
| 7 | 確認 | ✅ | 無 |

### 2.4 不變的部分

- 「日常 100% 緣緣、預設模式」不變（不觸發 skill 就是純緣緣）
- 「特殊模式必有 metadata」不變
- 鐵律放寬區（3.1）與絕對鎖死區（3.2）不變

## 3. v0.3 額外新增的實作細則（v0.2 未涵蓋）

以下是寫 `script-blender` SKILL 時補的細節、不算覆寫、算 v0.2 第 5 節「待決定」的部分回填。

### 3.1 #6「tier-A 引用使用規則」拍板：用過即忘

- tier-A 句子**不可整句寫進腳本**（即使是真的接近原話）
- tier-A 在 leak detector 中走「string leak」檢查、完全匹配 = 強警告、≥70% 重合 = 一般警告
- tier-A 只用於「理解這個人怎麼想」、生成時影響判斷邏輯、不影響字面

### 3.2 #4「leak detector 實作」拍板：三類檢查

詳見 `.claude/skills/script-blender/checks/leak-detector.md`。

- 名字洩漏 → warning + metadata
- tier-A 原句洩漏 → warning + metadata
- 5 個鎖死反胃詞 → 強制重生、不放行

### 3.3 #10「03-scripts 檔名加平台維度」拍板：採用

```
03-scripts/YYYY-MM-DD-平台-題目精簡-vN.md
03-scripts/YYYY-MM-DD-平台-題目精簡-vN.meta.yaml
```

### 3.4 腳本長度：60 秒內、240-300 字

中文每秒 4-5 字、整支 240-300 字。超過要請使用者選砍哪段、不自動砍。

### 3.5 雙檔輸出（v0.2 沒明說的）

- `<同名>.md` = 純腳本 + 最小 frontmatter
- `<同名>.meta.yaml` = 完整 metadata、含 borrow / loosened_rules / leak_warnings / 樣本厚度揭露 / 偏移計數
