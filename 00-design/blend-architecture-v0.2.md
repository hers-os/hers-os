## 1. 已拍板：核心理念（沿襲 v0.1）

> 「**把別人吃進去、用自己的嘴講出來。觀眾只記得緣緣。**」

- **主體唯一**：緣緣是主大腦、不可被取代、不可被稀釋到面目模糊
- **小大腦隱形**：references（楊天真 / 鄧紫棋 / 蔡依林 / 三國 / 孫子 / 鬼谷子⋯⋯）是思維滲透器、絕對不對外掛名
- **嘴是緣緣的**：產出 100% 用緣緣的口頭禪 / 句法 / 鈎子、不混入別人語感（**例外見第 3 節「可放寬區」**）
- **骨子可調**：緣緣的判斷層 + 一點別人的判斷層、比例可控、可審計
- **結果反推設計**：不追求前期完美、靠 feedback loop 校準

## 2. 已拍板：Q1–Q4

### Q1：借用方式 = **A（解讀 1）**

> 「整體氛圍滲透、但嘴 100% 緣緣」

- 楊天真會用什麼角度看議題、滲透在每句的**判斷邏輯**裡
- 但句子本身用的是**緣緣的字、緣緣的口頭禪、緣緣的句法**
- 結果：整支腳本「氣場像楊天真會挑這個議題、但聲音 100% 緣緣」

⚠️ **實作注意**：A 解讀 1 比 v0.1 預設的 C 層級制更難實作、SKILL prompt 要寫清楚「邏輯滲透 vs 嘴感污染」的差別、產出後要走嚴格 leak detector。

### Q2：6 個面向的可借 / 鎖死分配 = **同意預設**

| 面向 | 狀態 |
|---|---|
| 角色身份（妳是 ___ 型的人） | 🚫 鎖死 |
| 服務對象（替 ___ 說話） | 🚫 鎖死 |
| 反對對象（反對 ___） | ✅ 可借 |
| 判斷標準（怎麼判好壞） | ✅ 可借 |
| 使命（推什麼 / 避免什麼） | ✅ 可借 |
| 內容邊界（不講 / 不像誰） | 🚫 鎖死 |

**口訣**：「**妳是誰、妳替誰、妳的紅線**」3 條神聖鎖死；「**妳怎麼判、妳反對什麼、妳要推什麼**」3 條可借。

### Q3：多人混 = **C**

- 第一版**一次只借一個 reference**
- 跑滿 20 支腳本、累積偏移審查通過、再開放多人混

### Q4：比例呼叫方式 = **B + C**

- **預設值**：日常一律 100% 緣緣、不用下指令
- **特殊模式**：要借時用 `/blend` 命令、明確記錄

預定命令格式（待 SKILL 實作時定稿）：
```
/blend topic="<題目>" borrow="<reference>:<層>[<強度>]"
範例：
/blend topic="為什麼我不接低價業配" borrow="楊天真:判斷標準[中]"
```

## 3. 已拍板：鐵律分區（特殊模式時的放寬規則）

### 3.1 啟動 `/blend` 特殊模式時、可微量放寬的（限該支、限該層、必有 metadata）

| 條目 | 來源 | 放寬說明 |
|---|---|---|
| **鐵律 2「不污染嘴」** | 架構文件 v0.1 | 借「判斷層」時、句感 / 用字偏好可微量滲透；metadata 必須記錄；緣緣事後審查、覺得太像可撤回 |
| **style-guide 紅線 5「不混 A/B 文體」** | `voice/style-guide.md` v0.2 | 特殊模式可能需要混兩種文體、metadata 記錄 |
| **反胃詞清單（部分）** | `voice/style-guide.md` v0.2 | 看具體 reference、可放幾個；但「**寶寶 / 乾貨 / 絕 / YYDS / 泉**」5 個鎖死、跟誰借都不放 |

### 3.2 絕對鎖死（不管什麼模式）

| 條目 | 來源 |
|---|---|
| **鐵律 1「不掛名」** | 架構文件 v0.1 |
| **鐵律 3「不無聲偏移」** | 架構文件 v0.1（這條本身是用來防其他鐵律放寬後失控的監視器） |
| **CLAUDE.md 最高原則「誠信為本」4 子原則** | `CLAUDE.md` |
| **CLAUDE.md 第一層 6 紅線** | `CLAUDE.md` |
| **brand-facts.md 4 紅線** | `brand-facts.md` |
| **style-guide 紅線 1-4** | `voice/style-guide.md` v0.2 |
| **隱含紅線**：政治 / 客訴 / 炫富 / 同業比較 | 緣緣 Q&A 第 32、35 題 |
| **核心反胃詞 5 個**：寶寶 / 乾貨 / 絕 / YYDS / 泉 | `voice/style-guide.md` v0.2 + Q&A 第 27 題 |

### 3.3 放寬時必走的紀錄程序

任何放寬都不是「靜默放行」、必須在腳本 metadata 標記：

```yaml
loosened_rules:
  - 鐵律2-不污染嘴: 借楊天真[判斷標準層]、強度=中
  - style-guide-紅線5: 混 A/B 文體、佔比 30/70
review_status: 待緣緣事後審查
```

「以正合、以奇勝」精神：奇兵也要有紀律、不是脫離框架。

## 4. 已拍板：核心架構（沿襲 v0.1、不變）

- **三大模組**：主大腦（緣緣本人）/ 小大腦（references、隱形）/ 嘴（samples、強制套用）
