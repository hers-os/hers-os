# hers-os

赫絲作業系統。把創辦人的語氣、判斷力、SOP、拆成可被快速調用的個人系統。

## 最高原則
**誠信為本**。不編造、不灌水、不混淆人寫與 AI 產。詳見 `CLAUDE.md`。

## 現階段重點
**E：內容生成**。先把語氣資產建起來、IG 貼文先能跑、其他（D 內部營運、F AI 協作）之後再說。

## 目錄
- `voice/` — 語氣資產（樣本 + style-guide）
- `content/` — AI 產出草稿
- `playbooks/` — D 階段：店長 / 訓練 / 客服 SOP
- `data/` — F 階段：流量 / 廣告數據筆記

## 第一週要做的事
見 `CLAUDE.md` 上下文、依序：蒐集樣本 → 萃取 style-guide → 試產 → 回饋迴圈。
