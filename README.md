# hers-os

> 赫絲作業系統 — 給 AI 寫短影音腳本的「外掛大腦」。

主要產出：IG Reels / TikTok（< 60 秒）短影音腳本、由 AI 協助、但對齊緣緣的人格、調性、案例、禁忌。

---

## 模組

| 模組 | 狀態 | 用途 |
|------|:----:|------|
| `01-data-brain/` | 🟢 建構中 | **知識層**：人手填的品牌大腦（13 節）+ 案例庫 |
| `02-state/` | ⚪ 未建 | **狀態層**：機器寫的 JSON（觀看數 / 計數 / log） |
| `03-scripts/` | ⚪ 未建 | AI 生成的腳本歸檔 |
| `04-prompts/` | ⚪ 未建 | 腳本生成 prompt 模板 |

> 設計原則：知識層（人寫的 markdown）與狀態層（機器寫的 JSON）嚴格分開。

---

## 快速上手

1. 讀 `01-data-brain/README.md` 了解品牌大腦結構
2. 打開 `01-data-brain/_questions/stage-1.md` 開始填 50 題
3. 答案整理進 `01-data-brain/brand.md` 對應節
4. 提煉 `01-data-brain/brand-summary.md`（< 1KB）
5. AI 生腳本前讀 summary + 完整 brand.md + cases.md

---

## 三大鐵律

1. **AI 禁止虛構** — 不在大腦裡的數字 / 案例 / 口頭禪、AI 不能掰
2. **規則寫在資料層** — 能用 schema / lint 擋的、不靠 AI 自律
3. **缺核心節 → 拒絕生成** — `brand.md` 的 [0] [1] [3] 任一節空白、AI 必須拒絕生腳本
