# 階段 1 — 50 題（我是誰）

> 涵蓋節：[0] 基本資料 / [1] 核心專長 / [3.0-3.2] 內容調性 / [5] 禁忌邊界
> 完成標準：填完所有 50 題、AI 能寫出 3 支「有你味道」的腳本通過驗收
> 解鎖：階段 2（受眾 + 鈎子庫 + 季節節點）

---

## A. [0] 基本資料（題 1-8）

1. 你希望腳本裡 AI 怎麼稱呼你？（本名 / 暱稱 / 第三人稱）
2. 一句話介紹自己給陌生人、你會怎麼講？
3. 你的帳號名字背後有故事嗎？（沒有也 OK、寫「無」）
4. 你經營這個帳號多久了？
5. 目前粉絲量級（百 / 千 / 萬 / 十萬+）？這影響 AI 用「分享」還是「教學」口吻
6. 你住在哪裡？文化梗 / 在地語言要不要進腳本？
7. 你目前每週發幾支影片？
8. 一支影片平均多長？（< 15s / 15-30s / 30-60s）

---

## B. [1] 核心專長（題 9-23）

9. 同領域有 100 個人、為什麼粉絲要追你不追別人？
10. 你最常被問的 3 個問題是什麼？
11. 你最擅長解的問題是什麼？（具體、不要寫「教大家變美」）
12. 你做過 / 學過什麼讓你「有資格」講這件事？
13. 你有沒有一個獨家命名的方法 / 步驟 / 公式？
14. 你最反對業界的哪個說法？為什麼？
15. 別人講這個主題會講錯什麼？你會講對什麼？
16. 你最不想被歸類成哪一種創作者？
17. 你最希望被歸類成哪一種創作者？
18. 你的「獨門知識」是從哪裡來的？（書 / 經驗 / 老師 / 失敗）
19. 別人花一年學會的事、你花多久學會？
20. 你最近 3 個月學到的新知識 / 新洞察是什麼？
21. 你看到同行的內容、最常皺眉的是什麼？
22. 你看到同行的內容、最常欣賞的是什麼？
23. 如果只能用一句話定義你的專長、那句話是？

---

## C. [3.0] 整體調性（題 24-28）

24. 你的語氣偏哪幾種？（理性 / 溫柔 / 嗆辣 / 幽默 / 知性 / 直白 / 文青 / 反差、選 1-3）
25. 你的影片情緒基調是什麼？（療癒 / 燃 / 銳利 / 鬆弛 / 壓抑爆發 / 冷靜⋯⋯）
26. 你偏好短句堆疊、長句鋪陳、還是混合？
27. 你旁白語速大概每秒幾字？（不確定就開計時器念一段算）
28. 你的視覺風格偏哪幾種？（極簡 / 高彩 / 暗調 / 復古 / 手寫感 / 拍立得、選 1-3）

---

## D. [3.1] 口頭禪 / 慣用句（題 29-33）

29. 你最常掛在嘴邊的 5-10 個口頭禪是什麼？
30. 你影片開場最常用哪 2-3 句？
31. 你影片收尾最常用哪 2-3 句？
32. 你最常用的比喻 / 類比是什麼？（例：「這就像⋯」）
33. 你最常用的語助詞 / 嘆詞？（「欸」「對吧」「真的」⋯）

---

## E. [3.2] 禁用詞 / 禁用語氣（題 34-43）

34. 看到哪些字 / 詞你會起雞皮疙瘩、絕對不會出現在你的腳本？
35. 哪些「網紅口吻」你絕對不要？（例：嗲、裝萌、灑狗血）
36. 哪些開場句你絕對不用？（例：「大家好」「不知道你們有沒有⋯」）
37. 你絕對不對觀眾用的稱呼是？（「家人們」「寶貝們」「老鐵」⋯）
38. 哪些結尾句你絕對不用？
39. 哪些句型你不要？（疑問句連發 / 排比堆砌 / 條列 1234⋯）
40. 哪些情緒你不演？（憤怒 / 哭腔 / 撒嬌 / 賣慘）
41. 哪些講話節奏你討厭？（太快 / 太慢 / 太多停頓 / 一氣呵成）
42. 哪些「販賣感」你絕對不要？（限時優惠倒數、緊迫話術）
43. 哪些業界專業術語你刻意不用、要翻成白話？

---

## F. [5] 禁忌邊界（題 44-50）

44. 有沒有什麼議題、就算流量爆也絕對不碰？
45. 有沒有什麼產品 / 品牌、就算給很多錢也不接業配？
46. 你願意露出家人 / 朋友 / 寵物嗎？哪些不行？
47. 你不希望腳本提到的個人歷史是？
48. 平台演算法上、你絕對不做的「博流量小手段」是？
49. 法規上你領域有哪些紅線？（醫療 / 藥品 / 投資 / 法律宣稱）
50. 看到別人哪種風格 / 內容、你絕對不要被歸類成那樣？
